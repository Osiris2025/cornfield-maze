# Corn Field Maze — Implementation Plan (T1–T24)

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship Corn Field Maze on iPhone — a third-person gingerbread cookie in a corn maze: reach the pot of gold, survive the rain, outrun the Crumb Beast — with a player character Todd actually likes, working touch controls, atmosphere that reads, and a signed device build.

**Architecture:** Plain Unity C# MonoBehaviours, **no assemblies, no packages**. The whole world is built at runtime from code (`GameBootstrap.Start()` → `MazeGenerator` → `MazeWorldBuilder` → player/beast/gold/audio/weather/sky). The **one** asset that is allowed to be a deliberate model rather than a primitive assembly is the player: `GingerbreadMesh`.

**Tech Stack:** Unity **6000.3.23f1** (pinned), URP, C#, procedurally generated meshes/textures/audio in code, Xcode 27.0 for iOS, git, bash verify scripts.

**Art direction:** **Icing-and-dough.** Warm baked browns, raised white icing ribbon, gumdrop accents (red/green/yellow domes), against a dusk field — but it is **not locked past the cookie**: M0's verdict sets the language for everything after it.

**The rejected asset (drives everything):** Todd, 2026-09-17 — *"we are very unhappy with the gingerbread man."* The player is ~40 Unity primitives. See `docs/DECISIONS.md` §M0.

**Project location:** `/Volumes/files2/CornFieldMaze`

## Core data (existing, keep honest)

**`MazeData`:** `width, height, IsWall[x,y], StartCell, GoldCell, StartWorld, GoldWorld, solution path`.
**`FarmRig`:** `Hips, Torso, ArmL/R, ForeL/R, LegL/R, ShinL/R` — the joint set `GingerbreadMesh` returns. **Keep this contract**; the animation code depends on it.
**Constants that must stay in one place each:** `LaneHalf = 0.42` (lane half-width), `DissolveRainSeconds = 210`, `WalkSpeed 4.4` / `RunSpeed 7.4`, storm onset ~20 s, beast spawn ~5 s.

## The contract that matters

```
GingerbreadMesh.Build(parent, out FarmRig rig, out List<Material> mats, out List<bool> icingFlags) -> Transform model
```
- The returned `model` is the thing `ApplyDissolve` scales and the thing the camera follows.
- `mats` + `icingFlags` are how rain dissolve knows **which surfaces are icing** (icing washes off first). A replacement that drops this list breaks the dissolve and is a defect.
- **Dough may restructure the mesh and split the file — but this signature, and the `FarmRig` joint names, are the interface.** Changing them is a Harrow-level decision.
